# C++ 포인터, 배열, 구조체 정리

## 1. 포인터 기본 개념

- `int* p = &a;`
  - 일반 변수 `a`의 주소를 포인터 `p`에 저장.
  - `int* p = a;`는 **일반 변수에 &가 없는 경우 오류 발생**.
- 배열일 경우:
  - `int arr[5] = {10, 20, 30, 40, 50};`
  - `int* p = arr;` → `arr` 자체가 배열의 시작 주소를 의미하므로 &를 붙이지 않음.
  - `p+1` → 배열 인덱스 기준으로 다음 요소 주소로 이동 (자료형 크기 단위 자동 적용).

### 포인터 연산 이해

- `*p` : 포인터가 가리키는 위치의 값.
- `p+1` : 포인터가 가리키는 자료형 크기만큼 다음 위치로 이동.
- `p[n]` : `*(p+n)`과 동일.
- 일반 변수에서 포인터 연산 시 **쓰레기값 출력 위험**.

## 2. 배열과 포인터

- 배열 이름은 배열의 시작 주소.
- `int* p = arr;` 경우:
  - `*(p + 0)` → `arr[0]` 값 출력
  - `*(p + 1)` → `arr[1]` 값 출력
  - `p[2]` → `arr[2]` 값 출력
- 포인터 연산은 **자료형 단위로 이동**, 디버깅으로 확인 가능.
- 배열 아닌 일반 변수는 포인터 연산 거의 사용하지 않음.

## 3. 구조체 포인터

```cpp
struct Point { int x; int y; };
Point pts[2] = {{1,2}, {3,4}};
Point* pp = pts;
```

- `pp+1` → **다음 구조체 단위**로 이동 (8바이트 이동, int 2개 묶음)
- `pp->x` : 현재 포인터가 가리키는 구조체의 x 값 접근
- `pp->y` : 현재 포인터가 가리키는 구조체의 y 값 접근

### 구조체 배열 이해

- `pts[0]` → `{1,2}` (x=1, y=2)
- `pts[1]` → `{3,4}` (x=3, y=4)
- `pp+1` → pts[1]로 이동, `pp->y` → 4 출력
- `pts` 배열 안의 구조체는 **묶음 단위**로 포인터 연산 시 이동.

## 4. 포인터 타입 캐스팅

- 예제: `int* pI = (int*)sArr;`
  - short 배열을 int 포인터로 강제 캐스팅
  - **실무에서는 위험** (메모리 접근 불안정)
  - **실제로 필요할 때**: 네트워크 패킷 파싱, 메모리 매핑 등 특수 경우

### 요약

1. 배열: 포인터 연산 시 **자료형 크기 단위 이동**, 배열 인덱스와 일치.
2. 구조체: 포인터 연산 시 **구조체 단위 이동**, 멤버 접근 `->` 연산 사용.
3. 일반 변수: 포인터 연산 거의 사용하지 않음.
4. 포인터 캐스팅: 일반적으로 피하고, 특수한 실무 필요 시 주의해서 사용.
5. 직관적인 배열/구조체 포인터 이해가 기본, 바이트 단위 계산은 특수 상황에서 중요.

## 5. 디버깅 팁

- `(void*)p` : 포인터 주소를 일반 주소값으로 출력
- `*p` : 포인터가 가리키는 값 확인
- `p+1` : 포인터 이동 후 주소 확인
- 구조체 배열: 이동 후 `pp->x`, `pp->y`로 멤버 값 확인
