# C++ 포인터 정리 (Const 포인터 / Void 포인터 / 포인터 연산)

## 1. Const 포인터

### 1-1. `const int* p` : 대상 상수화
- 포인터가 가리키는 대상 변수의 값을 수정할 수 없음.
```cpp
int a = 10;
const int* p = &a;
*p = 20; // ❌ 불가
p = nullptr; // ✅ 가능
```
- 읽기 전용 포인터, 함수 매개변수로 많이 사용.

### 1-2. `int* const p` : 포인터 자체 상수화
- 포인터 자체를 변경할 수 없음. 가리키는 대상은 수정 가능.
```cpp
int a = 10;
int* const p = &a;
*p = 20; // ✅ 가능
p = nullptr; // ❌ 불가
```
- 고정된 대상만 수정 가능, 다른 변수로 포인터 이동 방지.

### 1-3. `const int* const p` : 대상 + 포인터 모두 상수
```cpp
const int x = 10;
const int* const p = &x;
*p = 20; // ❌ 불가
p = nullptr; // ❌ 불가
```

## 2. Void 포인터

- 자료형 없는 포인터 (`void*`)
- 특징:
  1. 어떠한 자료형 주소도 저장 가능
  2. 역참조 불가 (`*pVoid` 불가)
  3. 주소 연산 불가 (`pVoid + 1` 불가)
- 예시:
```cpp
void* pVoid = nullptr;
int a = 10;
float f = 1.2f;
pVoid = &a; // ✅ 가능
pVoid = &f; // ✅ 가능
```

## 3. 포인터 연산 정리

### 3-1. 기본 포인터 + 역참조
```cpp
int arr[3] = {10, 20, 30};
int* p = arr;
*p;       // arr[0] 값 (10)
*(p + 1); // arr[1] 값 (20)
```
- `*p + 2` : p가 가리키는 값에 +2
- `*(p + 2)` : p 위치를 +2만큼 이동 후 값 참조

### 3-2. 포인터 이동
- `p = p + 2` : 포인터 자체를 [2]번 위치로 이동
- `p + 2` : 임시 주소 계산, 포인터 위치는 이동하지 않음
- `*(p + 2)` : 임시 주소 역참조, 포인터 위치는 그대로

## 4. 배열과 포인터

### 4-1. 단일 포인터 배열 접근
```cpp
int arr[3] = {10, 20, 30};
int* p = arr;
*(p + 1) = 100; // arr[1] 수정
```
- p 자체 이동은 `p = p + 1` 형태로 해야 함

### 4-2. 배열 포인터
```cpp
int arr[3] = {10, 20, 30};
int (*pArr)[3] = &arr;
```
- 의미: 3개 요소를 가진 배열의 주소를 가리키는 포인터
- `pArr + 1` → 다음 배열 블록 주소 (2차원 배열에서 유용)
- 개별 요소 접근:
```cpp
(*pArr)[0] = 10;
(*pArr)[1] = 20;
```
- 단일포인터처럼 pArr + 1로 직접 개별 요소 이동 불가

## 5. 2중 포인터

```cpp
int a = 10;
int* p = &a;
int** pp = &p;
**pp = 20; // a 값 변경
```
- 포인터 자체를 함수 안에서 바꾸거나 다차원 배열 접근용

## 6. 문제풀이 시 햇갈리는 포인트

1. `*p + 2` vs `*(p + 2)` : 값에 +2 vs 위치 이동 후 값 참조
2. `int* const p` : 포인터 자체는 상수, 값 수정 가능
3. `const int* p` : 값 상수, 포인터 이동 가능
4. 배열 포인터 `int (*pArr)[3]` : 개별 요소 직접 이동 불가, 묶음 단위 이동
5. 2중 포인터 : 포인터 자체를 함수 안에서 바꾸거나 다차원 배열 접근용
6. `void*` : 자료형 무관 주소 저장, 연산/역참조 불가
7. 포인터 연산 시 `=` 없이 `p + n`만 하면 임시 주소 계산, 실제 포인터 위치는 변하지 않음
8. UB(Undefined Behavior) 발생 가능: 잘못된 포인터 접근, 배열 범위 초과, 자료형 불일치 등

## 7. 요약 감각

- 주소 전송 = 데이터 자체가 아니라 위치 전달
- 포인터 연산 = 임시 vs 실제 이동 구분 필수
- Const 포인터 = 안전 장치 / 설계 의도 표현
- Void 포인터 = 범용 / 자료형 무관 주소 저장
- 배열 포인터, 2중 포인터는 위치 이동과 묶음 단위 이해가 핵심
